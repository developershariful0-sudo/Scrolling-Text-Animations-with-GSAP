# Scrolling Text Animations with GSAP

A smooth, infinite marquee text animation powered by **GSAP (GreenSock Animation Platform)** that responds dynamically to the user's mouse wheel / scroll direction.

## ✨ Features
- **Infinite Marquee Effect**: Seamless looping text marquee banner.
- **Direction-Aware Animation**:
  - Scrolling down moves text smoothly to the left and flips the arrow (180°).
  - Scrolling up smoothly reverses text direction to the right (0°).
- **Smooth Transition**: Guarded wheel listener prevents animation stuttering during fast scrolling.
- **Modern & Responsive Design**: Built with clean HTML5, CSS3, and GSAP 3.

## 🚀 Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **[GSAP 3](https://greensock.com/gsap/)** (CDN)

## 💻 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/Scrolling-Text-Animations-with-GSAP.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Scrolling-Text-Animations-with-GSAP
   ```
3. Open `index.html` in your web browser (or use Live Server in VS Code).
